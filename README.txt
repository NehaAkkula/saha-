SAHA is a modern full-stack project and team management platform designed for organizations, startups, and students to manage projects, teams, and workflows efficiently.

Features:
- Authentication & Authorization
- Team Management
- Project Management
- Task Tracking
- Dashboard Analytics
- Notifications
- Role-Based Access Control
- Dark/Light Mode

Tech Stack:
- React.js
- Node.js
- Express.js
- PostgreSQL/MySQL
- MongoDB
